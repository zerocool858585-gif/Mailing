# Инструкция для коллеги: как скачать, запустить и перенести настройки

Эта инструкция для Windows и для человека, который только зарегистрировался на GitHub. Git в терминале знать не нужно: проект можно скачать обычным ZIP-архивом с сайта GitHub.

## 1. Получить доступ к проекту на GitHub

1. Откройте ссылку на репозиторий:

```text
https://github.com/kirtarget/senler_salebot_mailer
```

2. Если GitHub показывает ошибку `404` или пишет, что доступа нет, значит вас еще не добавили в проект. Попросите владельца репозитория добавить ваш GitHub-аккаунт в доступы.
3. После приглашения откройте письмо от GitHub или уведомление на сайте и нажмите `Accept invitation`.

## 2. Скачать проект на компьютер

1. Откройте страницу проекта на GitHub.
2. Нажмите зеленую кнопку `Code`.
3. Нажмите `Download ZIP`.
4. Дождитесь скачивания архива.
5. Распакуйте архив в удобную папку, например:

```text
C:\Projects\senler_salebot_mailer
```

Важно: лучше распаковать новую версию в отдельную новую папку, а не поверх старой. Так проще перенести настройки и не потерять старые файлы.

## 3. Установить Node.js

Node.js нужен, чтобы запустить локальный интерфейс проекта.

1. Откройте сайт:

```text
https://nodejs.org/
```

2. Скачайте версию `LTS` для Windows.
3. Запустите установщик.
4. На всех шагах можно оставлять настройки по умолчанию и нажимать `Next`.
5. После установки закройте и заново откройте PowerShell.
6. Проверьте установку:

```powershell
node --version
npm --version
```

Если появились номера версий, все хорошо.

Если PowerShell пишет, что запуск сценариев запрещен, дальше используйте `npm.cmd` вместо `npm`. Например:

```powershell
npm.cmd --version
```

## 4. Установить Google Chrome

Проект управляет обычным Chrome, поэтому Chrome должен быть установлен.

1. Скачайте Chrome с официального сайта:

```text
https://www.google.com/chrome/
```

2. Установите Chrome.

## 5. Открыть папку проекта в PowerShell

1. Откройте папку, куда распаковали проект.
2. Кликните правой кнопкой мыши по пустому месту в папке.
3. Выберите `Открыть в терминале` или `Open in Terminal`.

Если такого пункта нет:

1. Откройте PowerShell через меню `Пуск`.
2. Перейдите в папку проекта командой:

```powershell
cd C:\Projects\senler_salebot_mailer
```

Если ваша папка называется иначе, укажите свой путь.

## 6. Установить зависимости проекта

В PowerShell внутри папки проекта выполните:

```powershell
npm install
```

Если PowerShell блокирует `npm`, выполните:

```powershell
npm.cmd install
```

После этого в папке проекта появится папка `node_modules`. Ее не нужно редактировать руками.

## 7. Перенести настройки из прошлой версии

Перед переносом закройте старый и новый локальный интерфейс проекта, если они запущены.

Откройте две папки:

1. Старую папку проекта.
2. Новую папку проекта.

Из старой папки в новую нужно скопировать эти файлы и папки:

```text
senler\groups.json
salebot\audiences.json
senler\campaign.ui.json
salebot\campaign.ui.json
senler\uploads
```

Что это за файлы:

- `senler\groups.json` - список групп Senler.
- `salebot\audiences.json` - аудитории SaleBot.
- `senler\campaign.ui.json` - последняя сохраненная кампания Senler.
- `salebot\campaign.ui.json` - последняя сохраненная кампания SaleBot.
- `senler\uploads` - картинки, которые загружали через интерфейс.

Если какого-то файла в старой версии нет, это не страшно. Перенесите только то, что есть.

Что не нужно переносить:

```text
node_modules
npm-cache
.git
senler\logs
package.json
package-lock.json
scripts
```

Эти файлы либо создаются заново, либо относятся к самой программе. Если скопировать их из старой версии, можно случайно откатить обновление.

## 8. Проверить путь к картинке после переноса

В сохраненной кампании путь к картинке может остаться старым, например:

```text
C:\OldFolder\senler_salebot_mailer\senler\uploads\image.jpg
```

Если картинка не прикрепляется:

1. Запустите локальный интерфейс.
2. Откройте нужную кампанию.
3. Нажмите выбор картинки заново.
4. Выберите файл из новой папки:

```text
senler\uploads
```

5. Сохраните кампанию.

## 9. Запустить Chrome для работы скрипта

Проекту нужен отдельный Chrome в специальном режиме. Откройте новый PowerShell и выполните:

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="$env:USERPROFILE\Documents\Codex\chrome-senler" https://senler.ru/
```

Откроется отдельное окно Chrome.

В этом окне нужно войти:

1. В Senler.
2. В SaleBot, если будете делать рассылки SaleBot.

Важно: работать нужно именно в этом окне Chrome, которое открылось командой выше.

## 10. Запустить локальный интерфейс

Откройте еще одно окно PowerShell в папке проекта и выполните:

```powershell
npm run senler-ui
```

Если PowerShell блокирует `npm`, выполните:

```powershell
npm.cmd run senler-ui
```

После запуска откройте в браузере:

```text
http://127.0.0.1:4317/
```

Если страница открылась, проект запущен.

## 11. Быстрая проверка

В PowerShell внутри папки проекта можно выполнить:

```powershell
npm test
```

Если PowerShell блокирует `npm`, выполните:

```powershell
npm.cmd test
```

Если тесты прошли без ошибок, проект установлен нормально.

## 12. Как обновляться в будущем

Самый простой способ без знания Git:

1. Снова скачайте свежий ZIP с GitHub.
2. Распакуйте его в новую папку.
3. Скопируйте настройки из старой папки по списку из раздела 7.
4. Выполните `npm install`.
5. Запустите Chrome и локальный интерфейс.

Не заменяйте всю новую папку старой папкой целиком. Переносить нужно только настройки и картинки.

## 13. Частые проблемы

`GitHub показывает 404`

Вас не добавили в доступы к репозиторию или вы не приняли приглашение.

`npm не найден`

Закройте PowerShell, откройте новый и проверьте `node --version`. Если Node.js не найден, установите Node.js LTS заново.

`PowerShell запрещает запуск npm`

Используйте `npm.cmd`:

```powershell
npm.cmd install
npm.cmd run senler-ui
```

`Chrome не запускается командой`

Проверьте, где установлен `chrome.exe`. Чаще всего он здесь:

```text
C:\Program Files\Google\Chrome\Application\chrome.exe
```

`Интерфейс не видит Senler или SaleBot`

Проверьте, что Chrome запущен командой с `--remote-debugging-port=9222`, и что вход в Senler/SaleBot выполнен именно в этом окне Chrome.

`Картинка не прикрепляется`

Откройте кампанию в локальном интерфейсе, выберите картинку заново из папки `senler\uploads` и сохраните кампанию.

`Порт 4317 занят`

Скорее всего, проект уже запущен в другом окне PowerShell. Закройте старое окно или остановите запуск сочетанием клавиш `Ctrl+C`.
