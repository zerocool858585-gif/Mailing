Директория scripts предназначена для вспомогательных скриптов проекта Mailing.

Рекомендуемые файлы:
- send.py — основной скрипт отправки рассылок
- schedule.sh — обёртка для cron / планировщик
- utils.py — общие утилиты

Вы можете добавлять сюда скрипты напрямую или создавать поддиректории по языкам (python/, node/ и т.д.).

Файл создан автоматически ассистентом по запросу пользователя.
