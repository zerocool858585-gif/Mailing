# senler

Эта папка предназначена для файлов интеграции с Senler (сервис рассылок).

Структура (предложения):
- `config.example.json` — пример конфигурации с подсказками.
- `scripts/` — скрипты для отправки и управления рассылками.
- `README.md` — инструкция по настройке в этой папке.

Файл создан автоматически ассистентом по запросу пользователя.
