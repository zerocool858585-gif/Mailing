# Фильтры для рассылок Senler

Документация по использованию фильтров при создании рассылок в Senler через автоматизацию.

## Поддерживаемые фильтры

### 1. Фильтр по дате подписки (`subscriptionFrom`)

**Описание:** Ограничивает аудиторию только теми подписчиками, которые присоединились в указанную дату или позже.

**Параметр в campaign.json:**
```json
{
  "subscriptionFrom": "01.06.2025 00:00"
}
```

**Формат даты:** `DD.MM.YYYY HH:mm` (день.месяц.год часы:минуты)

**Примеры:**
- `"01.06.2025 00:00"` — подписчики с 1 июня 2025, 00:00
- `"05.08.2026 17:00"` — подписчики с 5 августа 2026, 17:00

**Как работает:**
1. Автоматизация открывает форму создания рассылки
2. Кликает "Добавить фильтр"
3. Выбирает "Дата подписки" из меню
4. Устанавливает значение в поле "с" (from)
5. Поле "до" (to) остается пустым (верхняя граница не установлена)

**Функция в коде:** `addDateFilter(cdp, campaign)` (строки 401-442)

---

### 2. Фильтр по группам подписчиков (`subscriberGroups`)

**Описание:** Ограничивает аудиторию только подписчиками, входящими в указанные группы Senler.

**Параметр в campaign.json:**
```json
{
  "subscriberGroups": ["123", "456", "789"]
}
```

**Формат:** Массив строк с ID групп подписчиков из Senler

**Примеры:**
```json
{
  "subscriberGroups": []
}
```
Пустой массив = фильтр не применяется

```json
{
  "subscriberGroups": ["430334", "474419"]
}
```
Рассылка будет отправлена только подписчикам из групп 430334 и 474419

**Как работает:**
1. Проверяется, есть ли ID групп в массиве `subscriberGroups`
2. Если массив пуст или не существует → фильтр пропускается
3. Если есть группы:
   - Кликается "Добавить фильтр"
   - Выбирается "Группы подписчиков" из меню
   - Для каждого ID из массива выбирается соответствующий option в select
   - Диспетчится событие change

**Функция в коде:** `addGroupFilter(cdp, campaign)` (строки 444-476)

**Примечание:** ID групп должны точно совпадать со значениями опций в select элементе на странице Senler.

## Порядок применения фильтров

При создании рассылки фильтры применяются в следующем порядке:

1. **Заполнение основных полей** → `fillEditor()`
2. **Добавление фильтра по дате подписки** → `addDateFilter()`
3. **Добавление фильтра по группам подписчиков** → `addGroupFilter()`
4. **Загрузка изображения** → `attachImage()`
5. **Сохранение рассылки** → клик по кнопке "Сохранить"
6. **Активация (опционально)** → `activateFromModal()`

## Проверка фильтров

При валидации рассылки скрипт проверяет:

✅ Наличие текста "Не используются фильтры" в описании рассылки
- Если текст присутствует → валидация **ПАДАЕТ** (фильтры не применены)
- Если текста нет → валидация может **ПРОЙТИ** (фильтры были применены)

**Функция проверки:** `validateGroup()` (строки 279-319)

```javascript
noFilterWarning: txt.includes("Не используются фильтры"),
// ...
ok: ... && !details.noFilterWarning
```

## Возможные проблемы и решения

### Проблема: Фильтр по группам не применяется

**Причины:**
1. Массив `subscriberGroups` пуст
2. ID групп не совпадают с опциями в select
3. Select элемент имеет другой селектор

**Решение:**
```json
{
  "subscriberGroups": ["430334"]
}
```
Убедитесь, что ID группы совпадает с реальным ID в Senler.

### Проблема: Ошибка "Group filter select not found"

**Причина:** На странице Senler нет select элемента с именем `filter[subscriber_group_ids][]`

**Решение:** Проверьте, что форма фильтра загружена полностью. Увеличьте `await sleep()` после клика на "Добавить фильтр".

### Проблема: "Не используются фильтры" — валидация падает

**Причина:** Хотя бы один фильтр не был применен

**Решение:**
- Проверьте консоль браузера в Chrome DevTools
- Убедитесь, что селекторы элементов совпадают с текущим UI Senler
- Увеличьте timeout значения в `waitFor()` вызовах
